Arthea
======

A multi-user-dungeon server in C#.  

Requirements
============

- C# compiler ([MonoDevelop](http://monodevelop.com)/[VisualStudio](http://www.microsoft.com/visualstudio/))
- MongoDB instance (I recomend [MongoHQ.com](http://mongohq.com))

Dependencies
============

The follow libraries are included in the project:

- [Jint](http://jint.codeplex.com) javascript parser for .NET
- [NUnit](http://nunit.org) for testing
- [MongoDB C# Driver](http://www.mongodb.org/display/DOCS/CSharp+Driver+Tutorial) for data storage
- [Thought.Net Telnet](http://www.thoughtproject.com/Libraries/Telnet/) Library, and excellent C# library for handling telnet protocols
